# sarorobat.github.io — Saro Sculpture | اساطیر ایران کهنسال

The official portfolio and archive of **Mahmoud Kohansal "Saro"** (محمود کهنسال ساروکلایی، متخلص به سارو) — Iranian sculptor, writer and researcher. Built and hosted **entirely on GitHub Pages**.

وب‌سایت رسمی و بایگانی کاملِ مجسمه‌ساز ایرانی، محمود کهنسال «سارو» — شامل سلسلهٔ «اساطیر ایران کهنسال»، آثار شهری، مقالات و ویدیوهای آموزشی. این وب‌سایت به‌طور کامل روی **گیت‌هاب پیجز** میزبانی می‌شود.

## 🛠️ Tech

Single-page static portfolio (HTML + Tailwind-style utility classes, base64-embedded media) served by GitHub Pages from the `main` branch — no build step, no external dependencies.
